From raw capture to product page

Keep the release train moving.

A screenshot gallery is a product explanation, not a pile of resized images. Screenker keeps the visual decisions and export work in one editable document.

  1. 1. Bring in the real product.Drop in raw captures from the app you just built. Keep the originals with the gallery project.
  2. 2. Compose the story.Give each screen a job: the hook, the moment, the detail that proves the app earns a download.
  3. 3. Check it like a customer.Preview the gallery in a store-style shelf before you export or publish.
  4. 4. Ship the right pixels.Export numbered PNGs for the device canvas you chose, including the new iPhone Duo inner and outer displays.

MCP, built in

Let your coding agent do the repeatable work.

Screenker exposes a comprehensive local MCP server. Claude, Codex, or another MCP client can inspect the live document, import captures, draft captions, apply edits, render previews, critique the gallery, and export a finished set.

It is not a browser automation trick. The agent works through Screenker’s real native document model, so every change is visible, editable, and stays under your control.

  • Render and inspect a slide at a different device size without changing the source deck.
  • Generate captions and apply consistent framing across a gallery.
  • Run a gallery critique before a screenshot gets near App Store Connect.
  • Export or publish a complete, numbered set through one tool call.
