Common questions

Devices cannot find each other. Nearby chat uses the local network. Both devices must be on the same network, and the app needs local network permission — check Settings if you declined it the first time.

Is there an account? No. SharedSpaceLab does not connect to a backend. Household data stays on your devices; nearby chat is peer-to-peer between them.

Siri. App Shortcuts provide short household-status and talk entry points.
